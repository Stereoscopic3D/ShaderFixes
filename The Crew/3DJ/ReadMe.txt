
DHR's 3DMigoto fix upgraded to geo-11 by 3DJ with help from MikeNX95.

Instructions:
    Download and extract the fix into the game folder
    Set direct_mode in d3dxdm.ini to what your 3D hardware expects.
    Download and open/import this driver profile in NVIDIA Profile Inspector if using an NVIDIA GPU (not sure if other GPUs will work) https://raw.githubusercontent.com/ThreeDeeJay/3DVSP/refs/heads/main/Resources/NVIDIA%20Profile%20Inspector/Profiles/The%20Crew.nip

When upgrading the 3DMigoto fix to geo-11 manually (not needed if you download the fix):
    Use geo-11 0.6.90 since all known older and newer builds crash at startup

Notes:
    Game's limited to 60FPS, so 144hz 3D Vision monitors should run at 120hz.
