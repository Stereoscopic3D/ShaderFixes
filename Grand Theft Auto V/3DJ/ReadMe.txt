Instructions:
    Download and extract the fix into the game folder
    Set direct_mode in d3dxdm.ini to what your 3D hardware expects.
    If geo-11 doesn't load (common in newer GTA5 builds), set the executables to run with Windows 7 compatibility. If that doesn't work, try downgrading to a mod-friendly build like 1.0.2699.16.
    Disable NVIDIA TXAA
    To fix shadows, lighting and reflections, try switching Shadows to Normal and back, and increase/decrease both separation and convergence with Ctrl+F3-F6 (overlay might stay up due to a bug)
    For 3D Vision, disable fullscreen optimizations for all executables
