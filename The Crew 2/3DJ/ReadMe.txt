
DHR's 3DMigoto fix for The Crew 1 upgraded to geo-11 by 3DJ with help from MikeNX95.

Instructions:
    Download and extract the fix into the game folder
    Set direct_mode in d3dxdm.ini to what your 3D hardware expects.
    Add the BattlEye/Ubisoft launcher bypasser (Steam still be required)

When upgrading the 3DMigoto fix to geo-11 manually (not needed if you download the fix):
    Use geo-11 0.6.90 since newer builds like 0.6.164 only render the silhouette of most geometry (almost everything is black)
    Set allow_platform_update=1 under [System] in d3dx.ini


Notes:
    Game's limited to 60FPS, so 144hz 3D Vision monitors should run at 120hz.
